# Implementation Plan

移設対象は `spawn_test_app` 呼び出し **203 箇所 / 20 ファイル**。うち `src/statuses/render_assembler/tests.rs` の 13 箇所は設計時点で Tier 2（例外）と判明しているため移設タスクを持たず、記録のみ行う。実際に移設するのは **190 箇所 / 19 ファイル**。

各移設タスクの共通手順は design.md「1 ファイル分の移設手順」に従う。可視性の壁に当たったら design.md「可視性の梯子」で段を判定し、Tier 2 と判定したテストは移設せず例外として記録する。

全移設タスクに共通する制約:

- 移設先ファイル名は `_it.rs` サフィックスで `tests/` 直下に置く（要件 1.3）
- テスト関数の対象・入力・アサーションを変更しない。削除・`#[ignore]` 付与・アサーション削減を行わない（要件 2.1, 2.2）
- 移設前に、同じモジュールを対象とする既存の `tests/*_it.rs` を確認し、重複する検証を新たに作らないこと（要件 2.4）
- 移設元に残った純粋な単体テストが引き続き通ること
